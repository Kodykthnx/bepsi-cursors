# Bepsi Cursors
This repository contains [Pogney's Bepsi cursors](https://drive.google.com/drive/folders/1JDB-pqrtc1E8c2J7UY6n7xhxivUwAsLr) that have been converted to X11 cursor format, using [Flachz's nordic scalable cursors](https://github.com/Flachz/Nordic-Cursors-Scalable) as fallback.

![A preview image of the cursors. Shown are Bepsi, Boot Beer, Supermeal, Christmas Bepsi, and Bopso cursors.](https://github.com/Kodykthnx/bepsi-cursors/blob/main/preview.png?raw=true)

All credit goes to the original creators:

[Pogney](https://sites.google.com/view/bepsis-site/table-of-contents?authuser=0) - Creator of original Bepsi Cursors
[Flachz](https://github.com/Flachz/Nordic-Cursors-Scalable) - Creator of Nordic Scalable Cursors
[Eliver Lara](https://github.com/EliverLara/Nordic) - Creator of original Nordic Cursors
